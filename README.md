## Структура

| Файл | Содержимое |
|---|---|
| `client_short.py` | базовый класс `ClientShort` — краткие данные клиента |

Запуск демонстрации:

```bash
python main.py
```

## Выбранная сущность — `Client` (клиент)

Из таблиц модели независимыми (без внешних ключей) являются `client` и `country`.
Выбрана сущность **клиент**, так как у неё наибольшее число полей:

| Поле | Тип | Описание |
|---|---|---|
| `client_id` | int | Идентификатор, целое > 0 |
| `last_name` | str | Фамилия |
| `first_name` | str | Имя |
| `patronymic` | str \| None | Отчество (может отсутствовать) |
| `phone` | str | Телефон в формате `+7XXXXXXXXXX` |
| `address` | str | Адрес |

Дальше в ЛР1–ЛР4 работа ведётся только с этой сущностью.
